# 新しいreferenceとv1適合の作業カード

REF-01は採用案を作成済み。REF-02〜REF-05はG-REFERENCEまたはREF依存の採択待ち。[共通手順](README.md)と既存の[ZB-P5計画](../miku-project-zero-base-implementation-plan-v20260810.md#zb-p5-java-cli適合)に従う。v1は既存contract / Schema / corpusが入力であり、legacy機能を足し合わせる移植ではない。

Java productionの新しいhelper/class名は計画上の候補である。実装開始時に既存の同責務classがあればそれを使い、名前のためだけの重複classを作らない。以下のJ-FOCUS class名も新規予定と明記されたものは作成後に使用する。
